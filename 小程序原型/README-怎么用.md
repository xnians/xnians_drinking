# 咕咚校园 · 小程序演示原型

> 这是 AI 按"打卡首页"需求直接生成的一套代码，你不需要会写，只需要看效果、提修改意见。

## 两个东西，先玩这个

### 1. 预览版-双击打开.html（现在就能玩）
用电脑浏览器双击打开即可，手机也能开。数据存在浏览器本机 localStorage，断网也能演示。
- 点「学霸同桌 / 吐槽搭子 / 软萌水精灵」切换人设
- 点「我喝了一杯 💧」，杯数 +1、进度条涨、冒出一句人设鼓励语；下面记录每一杯的时间，满 6 杯会提示完成
- 首页统计：连续达标天数、近 7 天杯数、今日完成度，以及近 7 天饮水小柱状图（纯前端，无外部库）
- 底部「陪伴」Tab 进入 AI 聊天页：可以跟当前人设说"我好累啊""考试好焦虑""今天不开心"，TA 用自己的语气回你。填了 DeepSeek key 走真实大模型并逐字流式输出、带上最近几轮上下文；留空 / 断网自动回退本地规则句库，本地回复也模拟逐字出现
- 底部「圈子」Tab 是校园社交：班级补水榜由本地打卡累加、自己高亮；勋章按真实行为点亮（首日打卡 / 连续 3 天 / 单日满 6 杯 / 连续 7 天 / 晚自习打卡 / 近 7 天 5 天达标）；点"提醒搭子喝水"会在动态流产生一条本地动态
- 底部「课表」Tab 是课表联动：8 个校园时段（早八/课间/自习/就餐/运动后/晚自习/睡前/考试周），按当前时间高亮"现在"，点任意时段看当前人设的场景提醒，不靠机械 45 分钟定时
- 页面左上角「← 返回总导航台」可回到根目录 `首页-总导航.html`

### 2. 真正的微信小程序代码（要装开发者工具看）
目录就是标准小程序结构：

```
咕咚校园小程序原型/
├── app.json          全局配置（标题栏、页面清单、底部Tab）
├── app.js            全局逻辑
├── app.wxss          全局样式
├── sitemap.json      收录规则
└── pages/
    ├── index/        打卡首页（四件套）
    │   ├── index.wxml  页面骨架（有什么字、什么按钮）
    │   ├── index.wxss  页面长相（颜色、大小）
    │   ├── index.js    页面逻辑（点按钮怎么变）
    │   └── index.json  本页配置
    ├── chat/         AI陪伴聊天页（四件套）
        ├── chat.wxml / chat.wxss / chat.js / chat.json
    ├── social/       校园社交页（四件套：排行榜/勋章/圈子动态）
        ├── social.wxml / social.wxss / social.js / social.json
    └── schedule/    课表联动页（四件套：8时段场景提醒）
        ├── schedule.wxml / schedule.wxss / schedule.js / schedule.json
```

## 怎么在微信开发者工具里看
1. 下载「微信开发者工具」（官网免费）
2. 新建项目 → 选「不使用云服务」→ 目录选本文件夹
3. 左边模拟器立刻看到和预览版一样的页面，可直接点

## AI 是怎么帮你写的
你只要用大白话提需求，例如：
> "做一个喝水打卡首页：顶部显示今天日期，中间一个圆圈显示喝了几杯/目标6杯，
> 可以切换三个人设（学霸同桌、吐槽搭子、软萌水精灵），下面一个大按钮'我喝了一杯'，
> 点一下杯数加一，人设随机说一句鼓励的话，并记录打卡时间。"

AI 就会生成上面这些代码；效果不对，你继续说"把按钮改成绿色""再加一个排名页"，它改给你。
