# 校园喝水提醒 · AIGC 提醒文案库

> 所属：豆包（AIGC 助手）｜分支：豆包-AIGC提醒素材包
> 适用对象：中学生 / 大学生　场景：教室、图书馆、宿舍、操场、食堂、晚自习
> 用法：按「人设 × 场景」直接取用，也可复制文末提示词模板交给 AIGC 批量生成。

---

## 一、三个人设语气说明

| 人设 | 语气基调 | 适合人群 |
|---|---|---|
| **学霸同桌** | 理性、鼓励，从记忆效率和身体状态切入，不煽情 | 自律型、备考型学生 |
| **吐槽搭子** | 毒舌但暖心，像损友念叨，带点梗，点到为止 | 怕说教、吃软不吃硬的学生 |
| **软萌水精灵** | 可爱撒娇、叠词、emoji，拟人化水杯视角 | 喜欢陪伴感、少女心用户 |

## 二、分场景提醒文案

### 场景 1 · 早八出门（宿舍 → 教室）

**学霸同桌**
- 早八人的水比早八的包子重要，出门前把水杯塞进书包，大脑含水率够了才听得进课。
- 今天第一节课别空着手去，水杯带上，路上那十分钟正好小口抿两口。

**吐槽搭子**
- 你上周已经把水杯落宿舍三次了，今天再落，我就把你水杯藏枕头底下。出门，看一眼桌面。
- 别仗着年轻就硬扛，早八不喝水，第三节课嗓子先罢工。

**软萌水精灵**
- 主人～你的小杯子还在桌上等你🥺 带上它，不然它会一个人孤单一整天。
- 咕嘟咕嘟，出门前给我灌半杯温水嘛，今天我陪你上课✨

### 场景 2 · 课间 10 分钟（教室）

**学霸同桌**
- 课间 10 分钟别钉在座位上，站起来去接杯水，顺便远眺，下节课注意力更集中。
- 这节课坐了 45 分钟，现在补水 200 ml，比下课猛灌一瓶更舒服。

**吐槽搭子**
- 别一到课间就低头刷手机，起来接个水，顺便活动下脖子，你颈椎已经在抗议了。
- 渴了才喝就晚了，趁现在没人排队，去，现在。

**软萌水精灵**
- 课间到啦～站起来走一走，带我去接杯水好不好🚰
- 咕噜咕噜，我肚子空啦，快去给我续上🥤

### 场景 3 · 图书馆 / 自习室（久坐专注）

**学霸同桌**
- 专注 50 分钟就起来接次水，眼睛看远处、嗓子补水分，效率比硬坐两小时高。
- 把水杯放在视线正前方，看到就喝一口，不用等口渴。

**吐槽搭子**
- 你都坐这儿俩小时没挪窝了，书是看进去了，水是一口没进。起来，接水，顺便让眼睛歇会儿。
- 别卷到脱水，脑子缺水会变慢，你卷不过一个缺水的自己。

**软萌水精灵**
- 自习辛苦啦，先喝一口水再继续，我陪你一起卷📚
- 眼睛累了就看看我，喝口水，我们再拿下一题💧

### 场景 4 · 食堂 / 就餐

**学霸同桌**
- 饭前先喝两口温水，别用汤和饮料代替白水，饭后半小时再补一杯。
- 今天打饭别只点奶茶，配一杯温水，肠胃更舒服。

**吐槽搭子**
- 别又端着奶茶当水喝，那是糖不是水，饭配白水才是正经事。
- 吃完饭别立马灌冰的，温水小口喝，下午不犯恶心。

**软萌水精灵**
- 吃饭的时候也别忘了我呀，饭前两口温水，身体会谢谢你🍚
- 奶茶甜甜的，但我才是陪你长长久久的那个💙

### 场景 5 · 体育课 / 操场运动后

**学霸同桌**
- 运动后小口多次补水，别一口气猛灌，温水或淡盐水比冰饮更护身体。
- 跑完别立刻停，慢走一圈，边歇边小口补水。

**吐槽搭子**
- 刚跑完 800 米就猛灌冰可乐？你是想爽三秒还是想胃疼一下午？小口喝水，听话。
- 出汗出了一身，别拿饮料糊弄，现在补水比买瓶运动饮料划算。

**软萌水精灵**
- 运动完要慢慢喝水哦，一口一口来，别咕咚猛灌🏃
- 辛苦啦，我在这儿等你，小口小口把我喝掉💦

### 场景 6 · 晚自习（傍晚到夜间）

**学霸同桌**
- 晚自习每节课间补一次水，别等到喉咙干才想起。
- 最后一节课前喝半杯温水，收尾不犯困。

**吐槽搭子**
- 熬到这会儿了，别靠咖啡硬顶，先喝口水，脑子清醒得更久。
- 晚自习别拿奶茶续命，那点糖喝完只会更困。

**软萌水精灵**
- 晚自习加油，累了就喝口水，我一直陪着你🌙
- 再坚持一下，喝口水，我们把今晚的任务完成✨

### 场景 7 · 睡前（宿舍）

**学霸同桌**
- 睡前一小时别大量灌水，小口润一下即可，避免半夜起夜影响睡眠。
- 明天的水杯今晚先灌满放桌上，明早出门不慌。

**吐槽搭子**
- 别临睡前咕咚一大杯，半夜跑厕所的是你不是我。抿两口就睡。
- 把明天的水先备好，省得明早又忘。

**软萌水精灵**
- 晚安啦，睡前抿一小口就好，别把我喝太撑哦😴
- 明天见，我会乖乖在桌上等你🌙

### 场景 8 · 考试周 / 熬夜冲刺（加餐场景）

**学霸同桌**
- 高强度用脑时更要规律补水，每 45 分钟一次，缺水会让反应变慢、焦虑加重。
- 桌上常备温水，少喝浓咖啡，水才是最稳的续航。

**吐槽搭子**
- 都考前周了，别把自己熬到脱水，书要背，命也要保，喝水。
- 咖啡一杯接一杯，水一口不碰，你这是在给心脏加负荷。

**软萌水精灵**
- 考试加油！紧张的时候喝口水，深呼吸，你可以的💪
- 我一直在桌边，累了就看看我、喝一口，我们一起撑过去🌟

## 三、AIGC 批量生成提示词模板

把下面模板交给任意 AIGC 工具，替换括号内容即可批量产出新文案：

```
你是一个面向[中学生/大学生]的校园喝水提醒助手。
请用【学霸同桌 / 吐槽搭子 / 软萌水精灵】的语气，
为【早八出门 / 课间 / 图书馆自习 / 食堂 / 运动后 / 晚自习 / 睡前 / 考试周】
场景写 5 条简短提醒文案，每条不超过 40 字，
要贴合校园生活、有画面感，不要说教，不要出现医学建议，
直接输出文案列表，不要解释。
```

**自定义人设模板：**
```
帮我设计一个喝水提醒 AI 角色：
性格：[例如：高冷但靠谱的学长]
说话习惯：[例如：短句、爱用反问、偶尔玩梗]

```

## 四、文案使用建议

- **推送时机**：课间、自习每 50 分钟、运动后、晚自习开始前，避免凌晨打扰。
- **轮换策略**：同一人设同一场景准备多条，避免每天重复同一句话导致被忽略。
- **A/B 测试**：三种人设可在班级小范围试用，看哪种打卡率最高再主推。
- **合规提醒**：文案只做生活方式提示，不替代任何健康建议；有基础疾病的同学遵医嘱。
