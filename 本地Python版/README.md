# 咕咚校园 · 本地离线打卡提醒（Python 版）

把小程序里的「打卡 + 三个人设提醒」做成一个**电脑本地程序**，
**完全离线、断网可用、双击即开**，专门用于答辩现场演示。

## 这是什么

- 一个用 Python 自带的 tkinter 写的桌面小窗口，不需要联网，也不用装任何额外软件。
- 包含核心卖点：**三个人设（学霸同桌 / 吐槽搭子 / 软萌水精灵）× 打卡鼓励语 × 定时提醒弹窗**。
- 今天喝了几杯、几点喝的，都存在本机 `data.json`，第二天自动清零。

## 怎么运行（答辩现场）

1. 电脑装了 Python 3.8 或更高版本（安装时勾选 *Add Python to PATH*）。
2. **双击 `启动本地版.vbs`** 即可（无黑窗，推荐）。
   - 如果双击没反应，就双击 `启动本地版.bat`（会留一个命令行窗口）。
3. 也可以在本目录打开命令行，运行：
   ```
   python drink_local.py
   ```

## 功能说明

| 功能 | 说明 |
| --- | --- |
| 今日打卡 | 点「我喝了一杯」，杯数 +1，自动记录时间 |
| 目标进度 | 默认每天 6 杯，进度条实时显示 |
| 连续达标 | 连续几天喝满 6 杯会累计 streak，跨天自动判断保留 / 清零 |
| 近 7 天图 | 窗口内用 Canvas 画近 7 天饮水小柱状图，仅标准库 |
| 三个人设 | 顶部切换，当前人设高亮，说的话风格不同 |
| 打卡鼓励 | 每打一次卡，当前人设随机说一句鼓励 |
| 定时提醒 | 默认每 45 分钟弹一次提醒窗，可改间隔、可开关（本地版保留可配间隔兜底） |
| 完成庆祝 | 喝满目标后提示达成，不再打扰 |
| 联网陪聊（可选） | 填了 API_KEY 才出现聊天框；带最近几轮上下文记忆，无网 / 失败静默兜底，不影响本地打卡 |
| 本地存档 | `data.json` 保存杯数 / 记录 / 连续天数 / 近 7 天历史 / 人设 / 设置，跨天自动归档归零 |

## 和小程序 / 桌面单机版的区别

- **小程序**：手机端，含陪伴聊天、圈子排行榜、课表联动，需要微信。
- **本本地版**：电脑离线演示，只保留「打卡 + 三个人设提醒」最核心的 AIGC 卖点，
  断网也能跑，答辩现场不怕没网。
- **队友的桌面单机版**：机械固定弹窗，无人设、无随机话术；本版有人设、有随机鼓励。
